# История из картотеки Excel

`card_file_to_history.py` делает из таблиц одной компании файл `history.json`, который загружает команда Кассы
`import-history` (см. `server/src/admin/history.ts` и README, раздел «Сборные грузы»). Таблицы только читаются.
В репозитории лежит скрипт; сами таблицы и `history.json` сюда не кладутся: в них имена и долги клиентов.

Нужны Python 3 и `openpyxl`.

```sh
python3 -I tools/express/card_file_to_history.py \
    --card "Картотека клиентов 2026 (по дням).xlsx" \
    --waybill "247 ... 06.11.2026.xlsx" --waybill "248 ... 07.11.2026.xlsx" \
    --name 413=Ахмад \
    --out history.json
```

Что читается:

- **Картотека, лист «Рейсы 2026».** Строка на клиента (№, имя, код), колонка на рейс («67 Рейс / 03.01.26»: номер и дата
  прибытия), в клетке сумма клиента за рейс. Колонки с названиями месяцев это подытоги, они пропускаются.
- **Картотека, листы месяцев.** Оплаты клиента по дням. Город оплаты по цвету букв: синий Ташкент, зелёный Андижан,
  остальное Москва. Клетка-формула «=939+3000» с примечанием «939 — оплата в Москве, 3000 — оплата в Андижане» это две
  оплаты. «Остаток прошлого месяца» первого месяца клиента это его долг на начало.
- **Картотека, лист «Контроль».** Копируется в файл: `import-history` после загрузки сравнивает с ним долги по месяцам.
- **Накладная рейса в пути (лист «ДС»).** Строки под шапкой «ПОЛУЧАТЕЛЬ, КОД, ...», дата погрузки над ней, водитель и
  госномера под строками. Дата выезда берётся из названия файла. Первая колонка говорит место в фуре («ГОЛОВА 3»,
  «ПРИЦЕП 5») и склад: «КУКОН ...» Коканд, «ТОШКЕНТ ...» Ташкент, без пометки Андижан. Вес это «ОБЩИЙ ВЕС»; колонки
  «ВЕС» и «РАСХОД» не переносятся.

У клиента обязательны и код, и имя: пустая строка без имени, рейсов и оплат пропускается; строке без имени, у которой
есть рейсы или оплаты, имя задаётся ключом `--name КОД=Имя`, иначе скрипт останавливается.

В конце скрипт печатает, что прочитал, и долги по месяцам рядом с «Контролем». Касса считает долг клиента за рейс до
цента, а картотека хранит третий знак, поэтому к концу года итог расходится с «Контролем» на десятки центов.
