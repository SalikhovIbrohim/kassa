# История из картотеки Excel, где у клиента свой лист

`card_file_to_history.py` делает из картотеки одной компании файл `history.json`, который загружает команда Кассы
`import-history` (см. `server/src/admin/history.ts` и README, раздел «Сборные грузы»). Таблица только читается.
В репозитории лежит скрипт; сама таблица, `history.json` и список замечаний сюда не кладутся: в них имена и долги клиентов.

Нужны Python 3 и `openpyxl`.

```sh
python3 -I tools/cosmo/card_file_to_history.py --card "Картотека.xlsx" --out history.json \
    --problems problems.csv [--waybills накладные/] [--until 2026-11-01] [--today 2026-11-24] [--name А413=Ахмад] [--force]
```

Что читается:

- **Лист клиента** («А54 Тимур»; читаются и «А-54», «A54», «Тимур А54», «54 Тимур»). Строка 2 называет колонки, в
  строке 3 первая клетка это долг на начало, ниже слева рейсы («ДАТА, РЕЙС, ..., СУММА Карго»), справа оплаты («ДАТА,
  ОПЛАТА ЗА КАРГО, СКИДКА %»). Колонки ищутся по названиям, поэтому лишняя колонка («За дорогу») не мешает.
- **Рейс** это номер: «412» или номер нового счёта «Р204» (буква русская или латинская), он становится рейсом 204.
  Строка «остаток» это долг с прежних времён: она прибавляется к долгу на начало. День прибытия рейса тот, который
  называет большинство его строк у всех клиентов; строка без даты берёт его.
- **Скидка** (в картотеке с минусом) уменьшает долг как оплата с пометкой «Скидка», днём оплаты над ней.
- **«Однаразовые»**: разовые клиенты, строка на груз с кодом, именем, суммой и оплатой.
- **«КЛИЕНТЫ»**: список клиентов с итогами. С ним сверяется долг каждого листа.
- Пустой лист, код которого есть на другом листе, пропускается. «ИТОГО» и «склатга» (аренда склада) не читаются.

`--waybills ПАПКА` даёт накладные рейсов (.xlsx, .xls; номер рейса и день в названии файла: «01.11.2026. R271.xlsx»,
«R-262 19.10.2026.xls», «608 рейс.xlsx»). Долг всё равно считается по картотеке; накладные только помогают: называют
рейс строке, где он записан не номером (если такую сумму этому клиенту начислил один рейс), дают день рейсу, которому
его никто не назвал, и показывают, где картотека и накладная расходятся в клиенте или рейсе («посмотреть», загрузке
не мешает). Для формата .xls нужен `xlrd`.

`--until ДЕНЬ` не берёт рейсы и оплаты этого дня и позже: с него их ведёт сама Касса, и дважды они считаться не должны.

Что нельзя прочитать как есть, печатается и пишется в `--problems` (CSV, открывается в Excel): дата, записанная не датой
или вне времени картотеки, рейс не номером, строка без кода, долг листа, не равный списку «КЛИЕНТЫ». История пишется,
только когда замечаний не осталось, или с `--force`: тогда спорные строки пропускаются, и сказано, на какую они сумму.
